# Plugins / 插件

**EN:** Plugins are maintained in **separate repositories** (not part of this repo).
To install a plugin, download its folder and put it into this `plugins/` directory,
then restart the app. See PLUGINS.md for the plugin API.

**中文：** 插件在**独立仓库**中单独维护（不属于本仓库）。安装方式：下载插件文件夹，
放进本 `plugins/` 目录，重启软件即可。API 见 PLUGINS.md。
