# 📢 Photo Watermark v1.7.0 — Release Notes / 更新公告

**EN:** Fixed dynamic-window theming timing (on_window_created now fires after the window is built, so themes color the real content — no white residue); gallery thumbnail selection highlight is preserved under themes. New: drag & drop a photo folder onto the window to load it.

**中文：** 修复动态窗口主题适配的时机 bug（on_window_created 改为窗口构建完成后触发，主题能上到真实内容，不再残留白底）；缩略图选中高亮在主题下保留。新增：把照片文件夹直接拖进主窗口即可加载。

## What's Fixed / What's New
- Fix dynamic-window theming timing / 修复动态窗口主题适配时机
- Keep gallery thumbnail selection highlight under themes / 缩略图选中高亮在主题下保留
- Drag & drop photo folder to load / 拖拽照片文件夹加载
